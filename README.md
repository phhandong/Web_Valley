# 溪谷小农场 · 四季生活

原创中文像素生活沙盒，使用 Vite、TypeScript、Canvas 2D，无服务器、无外部素材服务。包含四季天气、农耕、采集、料理、垂钓、交易、订单、换装和探索成长。

## 启动

```bash
npm install
npm run dev -- --host 127.0.0.1
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

开发默认 http://127.0.0.1:5173，正式预览默认 http://127.0.0.1:4173。以终端实际显示地址为准。不公开部署。

## GitHub Pages 部署

仓库包含 `.github/workflows/deploy-pages.yml`。推送到 `main` 后，工作流会安装依赖、运行测试、按仓库子路径构建并发布 `dist`；也可以在 Actions 页面手动运行。

首次使用时，在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。发布地址通常为 `https://<用户名>.github.io/<仓库名>/`。

## 操作

**砍树 / 挖石头**：靠近地图上的树干或岩石，按 **6** 选斧头、**7** 选石镐，再按空格操作面前格；也可点击同一棵树或岩石所占的地块。按一次挥动一次，也可按住空格或鼠标连续挥动（约每 0.5 秒一次）。基础／二阶／三阶工具砍大树需 6／4／3 击，挖岩石需 4／3／2 击，小型木石资源点与晶石矿脉需 2 击。每次有效命中消耗 1 点体力，饥饿时翻倍；最后一击才获得材料。树木基础获得 6 份木材、岩石获得 4 份石料，工具每升一阶多 2 份。清理后原位置可通行。树木从树苗开始，3 天后长成小树，6 天后成为可砍伐的大树；成熟时恢复碰撞。岩石清理进度永久保存。野外木材和石料采集点每 5 天恢复；清泉等剧情交互物不会被破坏。新农场增加两处岩石，旧存档不补放这两处障碍。

移动、换工具、打开菜单会取消当前采集动作，尚未命中时不扣体力；已命中进度会保存，刷新后可继续。满背包时保留最后一击，腾出空间再完成。完成后停止连续挥动，松开再操作下一目标。树木会摇晃、飞出木屑并倾倒，岩石逐步开裂和碎开。

**普通地面除草**：明显的立体草丛也可用锄头清理，操作脚下或相邻格，基础耗力 2，获得 1 份纤维。普通地面不会因此变成农田。农场清理后保持干净，野外草丛间隔 5 天恢复；细小地表纹理为背景。

地图内工具栏右侧的「背包」按钮或 **B** 键可以打开随身背包；再按 **B / Esc** 或右上角 × 关闭。背包显示实际的 24 格空间（可升级至 36／48 格），每格最多 99 份，支持分类、查看详情、食用、选择种子和一键合并整理。打开时暂停时间与移动，储物箱可存取物品。

新游戏约八成农田长有杂草，包括未来可扩建的区域。走到脚下或相邻田格，选择锄头（**1**）按空格或点击清理：消耗 2 点基础体力，获得 1 份植物纤维和 2 点经验；再锄一次松土，随后播种、浇水。纤维可出售（3 G）或存放。道路、免费食材和出入口保持通畅，清理后的杂草不会过夜重生。旧存档不会补长杂草；体验完整开局拓荒可先导出进度，再在设置中确认重新开始。

| 按键 | 用途 |
| --- | --- |
| WASD / 方向键 | 按住连续移动 |
| 1–7 | 锄头、播种、水壶、采收、鱼竿、斧头、石镐 |
| 空格 / 鼠标点击 | 操作脚下或相邻格；农田内优先脚下 |
| E | 进入房门、商店、场景出口，采集或探索标记 |
| B / M / C / J | 背包、地图、图鉴、手记 |
| Esc | 关闭窗口；无窗口时打开设置；钓鱼时收竿 |

所有普通窗口支持右上角关闭按钮、Esc 或点击窗口外关闭。背包满的渔获面板需要先选择放生或替换物品。菜单暂停世界时间；失去窗口焦点或切到后台暂停模拟与音乐，不计算离线伤害。

地图内右上角的半透明状态框用两行集中显示日期、天气、等级、时间、金币和生命／体力／饱食；工具与种子栏集中在地图内底部。角色接近右上角之前，状态框会让到左侧，底部工具栏会暂移至上方，离开后回到原位。点击 − / ＋ 缩小或放大状态框（220–360 像素），▾ 展开待结算收入和手记入口。设置底部也可调整大小，偏好随存档保存。新手任务在 J 手记中查看。地图文字由高清文字层绘制，图块保持像素风。支持 1366×768 和 1920×1080 电脑窗口。

## 音乐与垂钓

背景音乐为原创五声音阶旋律，通过 Web Audio 本地合成。首次键盘或鼠标操作后开始播放，森林、石谷与夜间有不同音高或节奏。设置内可单独开关音乐、调整音量及开关劳作音效。浏览器静音时需要先解除浏览器静音。

在农场池塘、湖畔、海湾或山脊湖的标记旁选择鱼竿并使用。浮标固定落在水面，紧凑小游戏面板就近显示；咬钩会显示放大的感叹号、金色提示和提示音。收竿后需等待 1.2 秒并松开按键或鼠标，才能再次抛竿。追踪时按住空格或鼠标上升，松开下降。前 **3 条成功收入背包的鱼**使用入门难度：浮标宽、鱼速慢、2.8 秒提竿窗口。之后按抛竿轮换「轻松 → 标准 → 轻松 → 挑战」，累计收获不足 6 条时，挑战局暂用标准难度。难度显示在钓鱼面板中。

轻松／标准／挑战的提竿窗口分别为 2.2／1.7／1.25 秒，鱼速、浮标宽度和进度容错逐级变化。困难局失败后，下一竿会回到轻松局；入门阶段失败则继续入门。无效抛竿不推进轮次，刷新和过夜不重置轮次。鱼竿升级扩大浮标范围；辅助模式提供至少 2.2 秒反应时间、更宽浮标与更慢鱼速，奖励不变。失败或取消不会获得鱼。

原有农场、小屋、小镇、森林、湖畔之外，另有四张可解锁地图：

| --- | --- | --- | --- |
| 萤火秘林 | Lv.3，累计 300 经验 | 180 G | 野果、木材、萤火、每 3 天领取 3 颗野苹果 |
| 回声石谷 | Lv.5，累计 840 经验 | 400 G | 石料点、古碑、每 3 天领取 8 份石料 |

森林东侧上方路牌通往秘林，下方路牌通往石谷。湖畔南端通往海湾，石谷东侧通往山脊。在对应入口路牌旁按 E 查看并购买永久通行；等级达标自动免费开放。地图和手记里也能查看条件。无需同时满足等级和金币。

播种 +2 经验、收获每份 +6、鱼每条 +12、料理每份 +10、采集每份 +2、订单 +25。等级最高为 10；经验仍可继续积累。本版升级所需累计经验增加到原来的 3 倍。旧存档经验自动同比迁移一次，保留已经获得的等级与区域资格。

森林可以持续探索，但要留时间给资源恢复：

- 寻迹：调查北坡足印、池塘东侧羽毛、南径树刻，各 +8 经验；找齐后到入口附近的宝箱，领取 60 G 和 30 经验；宝箱领取后需恢复 3 天。
- 小狐狸：用 2 颗莓果换 25 G 和 15 经验，每 3 天一次。
- 清泉：池塘西侧休憩，恢复 20 生命、25 体力，每天一次。
- 所有标记按 E 互动，完成后光点消失。线索和清泉每天恢复，奖励事件间隔 3 天；野外食材间隔 3 天、木石点间隔 5 天。农场免费莓果每天供应，保障零资源时也可恢复。刷新网页不会重复发奖。

## 海湾与山脊建设

- 海湾有分层海浪、海鸟和海草；三处贝壳采集点各产 1 枚海贝，免费拾取，3 天恢复，售价 12 G。
- 海湾南端旧栈道旁按 E，用 20 木材、10 纤维、100 G 修复，永久开放南端两个海钓位置。
- 山脊有瀑布、水雾、飘落松针与山鸟；两处晶石矿脉各产 1 份石英，使用石镐敲两下，5 天恢复，售价 35 G。
- 山间休憩亭旁按 E，用 15 木材、20 石料、150 G 修复。修好后每天可歇脚一次，恢复 15 体力；体力满时不会消耗当天次数。
- 修复前显示所需材料、金币和效果，成功后一次性扣除，永久保留。海贝与石英纳入图鉴，首次发现后可出现在订单中。

## 经营规则

8 种作物、14 种鱼、6 种采集物、8 道料理。每季 14 天，新游戏从秋月开始，56 天循环。一天 06:00–次日 02:00，约 12 分钟。小屋可主动睡觉，经过入夜、星光和晨光的短暂过渡后进入次日，只结算一次。衣柜以角色图例展示发型、服装和帽子，可先预览再确认。作物仅在适季、已浇水的夜晚生长；跨季休眠不枯死，雨天自动浇水。

商店购买与出售使用不同颜色和明确标签，顶部突出当前余额，确认前显示交易总价与交易后余额。商店每日 08:00–20:00 营业，出货箱全天可用。按物品和数量出售，商店即时到账，出货箱次日到账。工坊和渔具店提供工具、背包与农田升级。劳作工具升级减少耗力并提高材料采集量；抛竿基础耗力始终为 5，饥饿时翻倍。

生命、体力、饱食度最高 100；饱食低于 20 劳作耗力翻倍，饱食为 0 会受饥饿伤害。02:00 或生命耗尽会被救回小屋，收取最多 100 G 的 10% 费用。农场每天有免费莓果，零金币、零体力也能恢复经营。

## 溪谷生活扩展：朋友、设施与今日见闻

- **村民**：阿禾、老舟、石叔每天 08:00—20:00 出现。17:00 后晴天会到广场、湖畔或工坊外，雨雪天留在店门附近。走近后面向人物按 E，或点击相邻人物。每天首次交谈 +2 好感，每人每天可赠一份非种子物品；赠送前预览，普通 +5、喜爱 +10。好感不衰减。新订单附带委托人，完成额外 +3 好感。
- **人物故事**：三位村民各有三章，分别在好感 10／30／60 时接取；每人每天最多完成一章，没有期限。人物手记可从 J 打开，查看目标、位置和纪念。老舟只统计任务接取后在湖畔收入背包的鱼，阿禾第二章需要接取后亲自制作沙拉。最终解锁苹果肉桂酱、烟熏鱼、香草干菇，并在地图留下分享摊、鱼篓和模型。
- **设施制作**：石叔工坊 Lv.2 开放洒水器（100 G、木材 5、石料 5）与烘干架（120 G、木材 10、纤维 5）；Lv.3 开放果酱罐（180 G、木材 10、石料 8）与蜂箱（200 G、木材 15、纤维 10）。设备收入独立设施收纳，不占背包。
- **布置**：顶部“布置”打开设施收纳。在农场选择设备后，用方向键或点击选格，Enter／确认按钮摆放，Esc 取消。布置暂停游戏时间，预览显示无效原因及浇水／采蜜范围。空闲设备可免费搬动或收回；加工中、有产物或蜂箱已有进度时须先完成并领取。道路、树木生长位置、作物、出入口和钓点不能占用；布置还会检查通路。
- **生产**：洒水器每天清晨浇四邻格，可跨越，当天新种或新摆需手动浇水。果酱罐加工两份同类莓果／苹果／草莓，烘干架加工两份同类鱼／坚果，一个夜晚完成。基础售价分别为原料总价 1.4／1.25 倍；故事配方加入草药，耗时两夜、售价为总原料价 1.6 倍。机器一批一领，不自动重复，满背包时产物保留。
- **花卉蜂箱**：金盏花适合春夏秋，雪铃花适合冬季；种子 20 G，三个浇水日成熟，花朵售价 25 G，可留田采蜜。蜂箱周围两格（含对角）有成熟适季花时，每两个有效夜晚产花蜜一份（60 G），无花暂停；开始生产时取最近花卉，等距按田格顺序，同花可供应多个蜂箱。
- **今日见闻**：雨后森林找两处痕迹获得蘑菇与草药；海湾开放后每第三天 12:00—18:00 可进入退潮洞穴，找到两处潮痕后开贝箱；山脊开放后晴天有 25% 概率预告流星，20:00—24:00 寻找两处星光后收集星屑。狐狸交换累计三次后可跟足印寻宝，每次事件结束冷却三天。手记和地图显示预告；错过以后可再遇见。
- **洞穴与领取**：涨潮后不能进入，已在洞内仍可完成当次探索并退出；高水位退出后当天关闭。调查、生产和奖励状态自动保存，刷新不重抽事件或重复领取；多物品奖励在背包容量不足时整体保留。
- **兼容**：旧 V1／V2 存档补齐关系、设施和见闻模块，不清空农场、不追溯历史狐狸交易；关闭页面和后台不计算离线生产。加工品新增独立背包分类，花蜜、加工品和星屑纳入图鉴。

## 存档与恢复

自动存档及上一份有效备份保存在 localStorage。每 15 秒和重要操作保存。支持 V1 迁移、旧 V2 自动补充音乐／界面／成长默认值；新增拓荒记录保存草丛清理、木石受损进度和设施修复状态；动作会话不保存，读档恢复为空闲。不删除原记录。损坏时优先读取有效备份，无法恢复时明确提示并阻止自动覆盖。

设置中可导入／导出 JSON，重新开始需要二次确认。**不同浏览器、localhost / 127.0.0.1、不同端口各自保存**，搬移进度请使用导出／导入。

## 代码与验证

- `content.ts`：物品、作物、鱼、配方、价格和升级成本。
- `world.ts`：九张地图的碰撞、交互点、采集点与出口。
- `engine.ts` / `inventory.ts`：游戏规则与原子库存交易。
- `balance.ts` / `ecology.ts`：等级门槛、资源恢复间隔、树木生长与存档状态。
- `overlays.ts`：钓鱼面板避让和 HUD 位置判断。
- `progression.ts`：等级、区域通行与森林探索事件。
- `fieldwork.ts` / `work-session.ts`：普通草丛、逐击资源、持续输入与修复设施。
- `tool-art.ts` / `regional-art.ts`：图标与挥动共享的工具像素图形、区域环境动画。
- `fishing.ts` / `music.ts`：浮标小游戏与原创背景配乐。
- `art.ts` / `scene-renderer.ts`：分层像素人物、地图与高清文字层。
- `ui.ts` / `main.ts`：HTML 菜单、输入、固定时间步进和暂停逻辑。
- `persistence.ts`：存档校验、迁移和备份恢复。

`npm test` 覆盖全年循环、农业、生命、背包、交易、订单、换装、钓鱼、存档，以及等级门槛、购买防重复扣款、森林奖励防重复领取与满包回滚。页面关闭不依赖 CSS 动画完成，兼容系统「减少动态效果」。
